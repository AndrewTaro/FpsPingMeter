# FPS Ping Meter
This modification allows you to customize the FPS and Ping indicators in World of Warships.

- Font Size
- Font Theme (Default or Light)
- Warning/Critical Thresholds

# Requirements
You must install the following for this mod to work:
- [TTaro Mod Config](../../../TTaroModUtils)

# Install
1. Download the zip.
2. Unzip the archive and you should get the `gui` and `ModSchemas` folders.
3. Move both to `(wows)/bin/(latest_number)/res_mods/`. So the path will look like `res_mods/gui/unbound2/PnFMods/FpsPingMeter.unbound`
4. Done!

# Note on `ModSchemas/`

> [!WARNING]
> These files are generated by my own config tool. Do not edit them, and do not copy one
> into another mod: the `id` inside names the player's settings file, so a reused `id` makes
> the framework refuse **both** mods' settings. Trouble from an edited or copied schema is
> not a bug in my mods.
